# upl-001 - Image upload with a 5 MB limit and automatic resize

| File | Change |
|---|---|
| be/package.json, package-lock.json | Added multer 2.0.2, sharp 0.33.5, @types/multer 1.4.12 (exact versions). sharp's prebuilt Windows binary loads under node and tsx on Node 20.20 (checked first, given the tsx/exceljs issue). |

| fe/src/components/ImageUpload.tsx | New: file input, upload on pick, previews, Remove, resize note, client-side 20 MB check. |
