# cmt-001 - Comments are open until the auction closes; afterwards read-only, nothing deleted

SRS: System - Comment Section, Req-1.

## Open/closed rule

| Auction (computed status) | Signed-in user | Guest |
|---|---|---|
| upcoming, active | sees the box and can post | sees comments and a "Log in to comment" link |
| ended (stored, or end time passed before the close job), cancelled | "Comments are closed" above the comments, no box | same, no link |

- `POST /api/auctions/:id/messages` on an ended or cancelled auction: 400 "Comments are closed for this
  auction". The check uses `effectiveStatus`, so it applies from the end time even before the close job.
  Unknown auction 404 and anonymous 401 as before. Seller and bidders alike can post while open.
- Comments are never deleted; `GET /api/auctions/:id/messages` still returns them after the close and
  after a cancel.
- An open page closes the box without a reload: at the end time through the countdown (which reloads the
  auction), and through a new `closed` event on the auction stream (`GET /api/auctions/:id/events`, sent
  after settlement and after a cancel; see ../realtime.md). If a post races the close, the server's 400
  makes the page reload too.
- The section heading stays "Messages" (existing specs use it); the closed notice and the guest link use
  the word "comment" as the SRS does.
