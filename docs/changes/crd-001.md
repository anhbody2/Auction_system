# crd-001 Only the leading bid locks credit

Date: 2026-10-20.

## Result

The behaviour was already built in rounds 1-2 (bid-001, sell-002, sys-002). The new tests found no
gaps, so no application code changed. To check that the tests can catch a regression, the outbid
release in be/src/routes/bids.ts was turned off temporarily: 3 of the 4 credit.lock tests failed. The
change was then reverted.
