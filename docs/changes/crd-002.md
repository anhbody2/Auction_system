# crd-002 - 'Credit' and 'Locked credit' instead of 'Available credit'

SRS: Customer - System UI, Req-1, Req-2.

## Reading of the SRS (assumption, to confirm with the product owner)

"Change available credit to credit, update new - locked credit" and "Only update credit after auction
closed" are read as: the headline figure is the balance, labelled **Credit**, which changes only on top up,
withdrawal and auction close. Next to it is **Locked credit** (held in active bids), which changes on bid and
outbid. The spendable amount (credit minus locked) is still enforced on the server but is not displayed.
