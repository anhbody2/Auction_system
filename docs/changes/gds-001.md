# gds-001 - My goods: add goods with uploaded images and list them

SRS: Seller - Manage Goods 3.11.3 REQ-1; Create Auction (image) Req-2 (image required when creating goods).

## Behaviour

- New page **My goods** (`/goods`, nav link "My goods"), separate from My auctions. It lists the seller's
  own goods with thumbnail, name, category, condition and a derived status.
- **Add goods** (`/goods/new`): name, description, category, condition and 1-8 uploaded images (the
  upl-001 `ImageUpload`). Without an image the form shows "Add at least one image"; the server checks it too.
- Derived status (be/src/lib/goods.ts `goodsState`): `sold` if an auction for it ended with a winner;
  `in_auction` if one is upcoming or active (an active one past its end time stays so until the close job
  ends it); otherwise `available` (also after a cancelled auction or one that ended without a winner).
  Goods with `goods.status = 'deleted'` are left out (soft delete comes with gds-002).

## API

| Endpoint | Notes |
|---|---|
| `POST /api/goods` | signed in. Body `{ name, description, categoryId, condition, images: string[] }`. 201 `{ goods }`. 400 field errors: name (3-255), description (10-5000), categoryId, condition, images ("Add at least one image", at most 8, "Upload the images instead of linking to them" for anything that is not one of this server's uploads). |
| `GET /api/me/goods` | signed in. The caller's goods, newest first: `{ id, name, description, condition, category, images, status, auctionId, ... }`. |

## Known

  need to know its random 32-hex name).
